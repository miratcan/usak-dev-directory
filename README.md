# Uşak Developer Directory

Uşak'taki yazılımcıların listesi. Kendini eklemek için PR aç!

## Nasıl eklenirim?

1. Bu repoyu fork'la
2. `developers.json` dosyasına kendini ekle
3. PR aç

### Format

```json
{
  "name": "Ad Soyad",
  "github": "github-kullanici-adi",
  "title": "Ünvan (ör: Frontend Developer)",
  "links": {
    "website": "https://example.com",
    "twitter": "https://twitter.com/kullanici",
    "linkedin": "https://linkedin.com/in/kullanici"
  }
}
```

### Kurallar

- `name` ve `github` zorunlu
- `title` ve `links` opsiyonel
- `links` altına istediğin kadar link ekleyebilirsin
- Alfabetik sıraya göre ekle (soyada göre)
- JSON formatını bozmamaya dikkat et
